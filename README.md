# The Business Unicorn

Modern multi-page website for The Business Unicorn: Ontraport email marketing automation, training, and free resources.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- MDX blog posts

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Contact form

Set `NEXT_PUBLIC_FORMSPREE_ENDPOINT` in `.env.local` (see `.env.example`). Without it, the form still succeeds locally for UI testing.

## Scripts

- `npm run dev`: development server
- `npm run build`: production build
- `npm run start`: start production server
- `npm run lint`: ESLint
